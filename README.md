## Entry

> feat: ship to prod at 4:59pm Friday — rollback plan is vibes and a prayer

## How it works

`main.py` (Python 3.13, standard library only) writes the commit message to `entry.txt` in `MAKEFUN_OUTPUT_DIR`, enforcing the competition gate (UTF-8, 1–159 characters, single line, not only whitespace) and verifying the file back byte-for-byte before exiting.
